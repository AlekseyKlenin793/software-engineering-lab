# Тестовые данные

В проекте используются следующие наборы тестовых данных:

| Файл | Назначение |
|---|---|
| users.json | Данные пользователей |
| products.json | Данные товаров |
| orders.json | Данные заказов |
| test-cases.md | Тестовые сценарии |

## Связи

Пользователь связан с заказом через `userId`.

Заказ связан с товаром через `productId`.
