# События января

## План работ

В январе планируется выполнение следующих задач:

1. Создание репозитория проекта.
2. Настройка GitHub.
3. Создание Wiki.
4. Подготовка документации.
5. Распределение задач между участниками.

## Практические работы

- Создание GitHub-репозитория.
- Настройка совместной работы.
- Работа с Wiki.
- Работа с Git.
